description=Download cadastral parcels of Croatian cadastral municipalities from the INSPIRE ATOM feed of the State Geodetic Administration (DGU) and add them to QGIS.
about=Browse the national INSPIRE ATOM download feed of the Croatian State Geodetic Administration (Državna geodetska uprava, DGU), pick a cadastral municipality (katastarska općina), download its GML data and add the layers you need to the project in one step.

    Features:
    - search by municipality name or ID, with or without Croatian diacritics
    - sorting by the Croatian alphabet (č, ć, dž, đ, lj, nj, š, ž)
    - downloads run in the background with progress, using the QGIS proxy and network settings
    - downloaded data is kept per municipality and reused, with a button to clear what the current project does not use
    - English and Croatian user interface

    Hrvatski: dodatak za preuzimanje katastarskih čestica po katastarskim općinama iz INSPIRE ATOM servisa Državne geodetske uprave.

changelog=2.0.0
    - Search by name or ID, diacritics optional
    - Correct Croatian alphabetical sorting
    - Downloads kept in one folder per municipality and reused; zip archives deleted after extraction; "Clear unused downloads" button
    - Background downloads with progress bar using QGIS network settings (proxy, SSL)
    - Layers added into a group named after the municipality; GML files with several feature types load as several layers
    - Works on Linux and macOS (path handling); prepared for QGIS 4 / Qt6
    - Croatian translation of the user interface
    - Feed parsed with Qt's XML reader; documents containing a DTD are rejected (protection against XML entity attacks)
    - Fixed: file list kept growing when switching municipalities; crash on feed entries without CRS information
    1.0
    - First version, used internally
